# UET.IS2099 — Nhập môn Cơ sở dữ liệu Quiz App

Hệ thống ôn tập **224 câu hỏi trắc nghiệm** môn Nhập môn Cơ sở dữ liệu tại Trường Đại học Công nghệ, ĐHQGHN (UET-VNU), kèm **cheatsheet lý thuyết** đầy đủ.

## Nội dung

- **184 câu ngân hàng ôn tập** (nhận biết / thông hiểu / vận dụng) + **40 câu hỏi vận dụng tình huống**, mỗi câu 4 lựa chọn, có đáp án và lời giải chi tiết
- **Chương 1 – Tổng quan hệ CSDL:** 46 câu (dữ liệu, CSDL, DBMS, kiến trúc ANSI/SPARC, ngôn ngữ, vai trò người dùng)
- **Chương 2 – Mô hình ER cơ bản:** 56 câu (44 câu ngân hàng + 12 câu vận dụng: thuộc tính, khóa, lực lượng, min–max, thực thể yếu, liên kết đệ quy, thực thể kết hợp)
- **Chương 3.1 – Mô hình dữ liệu quan hệ:** 54 câu (44 câu ngân hàng + 10 câu vận dụng: khóa ứng viên, khóa chính/ngoại, toàn vẹn thực thể – tham chiếu – miền, ánh xạ ER → quan hệ)
- **Chương 3.2 – Đại số quan hệ & cập nhật:** 68 câu (50 câu ngân hàng + 18 câu vận dụng: chọn, chiếu, hợp, giao, trừ, tích Descartes, nối, chia, gom nhóm, nối ngoài, thao tác cập nhật)
- **Cheatsheet 9 phần:** tổng quan CSDL, ER, EER, mô hình quan hệ, chuyển ER → quan hệ, đại số quan hệ, quy trình giải bài, dạng bài tập và checklist trước thi
- Công thức Đại số quan hệ hiển thị bằng **LaTeX** qua MathJax 3
- Lọc theo **chương**, **độ khó**, tìm kiếm nội dung
- Chế độ xem **từng câu** và **danh sách**, bảng tiến độ trực quan
- Nút **In / Lưu PDF** cho cheatsheet

## Cách sử dụng

Mở file `index.html` (hoặc `quiz_app.html`) trong trình duyệt web.

Không cần server — chạy trực tiếp offline (riêng công thức LaTeX cần Internet để tải MathJax).

## Yêu cầu

- Trình duyệt hiện đại (Chrome, Firefox, Edge, Safari)
- Kết nối Internet để tải MathJax và Tailwind CSS
